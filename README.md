# AI Exam Prep System

**AI-Powered Exam Preparation Platform** for competitive exams such as SSC, UPSC, and IELTS.  
The system leverages **CrewAI, Gemini LLM, and Serper API** to provide personalized learning experiences, including topic explanations, mock tests, interactive assessments, and data-driven study plans.

---

## Key Features

- **Previous Year Question Analyzer:** Extracts and analyzes questions from multiple PDF papers to identify high-priority topics.  
- **Topic Explainer:** Provides detailed explanations and examples for each topic.  
- **Mock Test Generator:** Creates exam-style tests with answer keys and difficulty levels.  
- **Interactive Live Test:** Conducts real-time Q&A sessions based on uploaded PDFs.  
- **Weakness Analyzer & Study Plan:** Evaluates performance to generate a personalized study roadmap.
